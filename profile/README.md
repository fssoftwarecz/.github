# FS Software

Vyvíjíme modulární software pro veřejnou dopravu a zákaznickou podporu. Systém **Skeleton®** pomáhá s konstrukcí, plánováním, řízením a analýzou dopravy. Nabízíme také modulární **CRM** pro správu zákaznické komunikace a podpory.

Více informací najdete na [fssoftware.cz](https://fssoftware.cz/).
